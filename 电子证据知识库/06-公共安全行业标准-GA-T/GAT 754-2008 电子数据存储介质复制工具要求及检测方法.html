GA/T 754—2008 电子数据存储介质 复制工具要求及检测方法 1 范围 本标准规定了电子数据存储介质复制工具的检测方法。 本标准适用于对用于复制电子数据存储介质存储的数据的软件和硬件设备进行检测。 2 规范性引用文件 下列文件中的条款通过本标准的引用而成为本标准的条款。凡是注日期的引用文件，其随后所有 的修改单(不包括勘误的内容)或修订版均不适用于本标准，然面，鼓励根据本标准达成协议的各方研究 是否可使用这些文件的最版本。凡是不注日期的引用文件，其最新版本适用于本标准。 GA/T755—2008 电子数据存储介质写保护设备要求及检测方法 3术语和定义 下列术语和定义适用于本标准 3.1 源存储介质 存储有要复制的数据的电子数据存储介质。 3.2 目标对象 destine object 从源存储介质复制获得的数据存储对象，包括镜像文件住面对齐备份和柱面非对齐备份。 3.2.1 镜像文件 image file 从源存储介质复制生成的一个或一组文件，从该文件或文件组中存储的数据可重新创建源存储介 质存储的数据比特流 的比特位。 3.2.2 柱面对齐备份cylinder aligned copy 将源存储介质逐比特复制到另一电子数据存储介质中，并对文件系统分区表和启动扇区做出适当 调整，使分区的第一个扇区与磁盘柱面边界对齐，并对调整所增加的扇区进行合理填充获得的数据存储 对象。 3.2.3 柱面非对齐备份 cylinder unaligned copy 将源存储介质逐比特复制到另一电子数据存储介质中，并且不调整文件系统分区表和分区启动扇 区获得的数据存储对象。 3.3 目标存储介质 destine data storage 用于存储目标对象的电子数据存储介质称为目标存储介质。 1

GA/T 754—2008 3.4 复制工具 duplication tool 读取源存储介质存储的数据并复制到目标对象的软件或硬件设备。 3.5 截短备份 truncated copy 由于目标存储介质的存储空间小于源存储介质的存储空间，复制源存储介质生成的柱面对齐备份 或柱面非对齐备份未包含源存储介质中存储的所有数据。 3.6 逐比特复制 bit-stream duplicate 将数据的每个比特位准确复制到另一目标数据中。 注：逐比特复制的对象可以是数据文件、磁盘分区、整个磁盘等。 3.7 隐藏数据扇区 hidden data sector 源存储介质中位于可用分区之外的扇区。 3.8 可见数据扇区 visible data sector 源存储介质位于可用分区之中的扇区。 3.9 损坏扇区 bad sector 是指由于物理损坏等原因，无法读取其存储的数据的扇区。 3.10 未解决错误 unresolved error 复制工具向源存储介质或目标存储介质发出指令时存储介质返回失败或错误状态码，如果复制工 具通过重发指令或改为执行其他指令仍然无法完成其所要实现的目的或仍然返回失败或错误状态码， 则称发生的错误为未解决错误。 3.11 合理填充 benign fill 在数据复制过程中，当源存储介质特定数据存储区域无法读取或目标存储介质存在剩余数据存储 区域时，向目标存储介质对应的数据存储区域填充不会与其他数据混淆的数据。 示例：比如填充常数 0 或“This dats is not from the source dats storage”等明显标识该数据不是来自源存储介质的 文本。 4 要求 4.1 接口可用性要求 复制工具应能使用其支持的所有接口复制数据。 4.2 目标对象要求 复制工具应生成镜像文件、柱面对齐备份或柱面非对齐备份。 4.3 完整复制要求 对于源存储介质所有可见数据扇区和隐藏数据扇区中的任一比特位，复制工具生成的目标对象中 都可获得与其相对应的比特位。 4.4 准确复制要求 如果源存储介质中的比特位可读取，复制工具生成的目标对象中对应的比待位与源存储介质中的 比特位数值一致。 2

GA/T 754—2008 4.5 错误处理要求 a） 如果从源存储介质读取数据发生未解决错误，复制工具应告知用户发生的错误类型和位置； b） 如果向目标对象写人数据发生未解决错误，复制工具应告知用户发生错误； c) 如果源存储介质中存在损坏扇区，复制工具生成的目标对象中对应的比特位应被合理填充。 4.6 存储空间不匹配处理要求 4.6.1 存储空间不足处理要求 a） 如果目标存储介质存储空间不足，复制工具应告知用户； b) 如果目标对象为柱面对齐备份或柱面非对齐备份，复制工具应选择不复制数据或使用目标存 储介质的所有存储空间生成截短备份； c）如果目标对象为镜像文件，且复制工具支持切换目标存储介质，复制工具应提示用户切换目标 存储介质，并在目标存储介质切换后在新的目标存储介质上继续写人镜像文件。 4.6.2 存储空间过剩处理要求 如果目标对象为柱面对齐备份或柱面非对齐备份，且数据复制后目标存储介质存在剩余存储空间， 复制工具应保留剩余存储空间的数据不变或对剩余存储空间进行合理填充。 4.7 写保护要求 如果复制工具可在未使用写保护设备保护源存储介质的情况下复制数据，复制工具应符合 GA/T755—2008中第4章规定的要求。 5 检测步骤 5.1 检测要求 a） 对于复制工具支持的所有访问接口，均应分别按照本章规定的方法逐一检测； b) 对于复制工具支持的所有目标对象，均应分别按照本章规定的方法逐一检测。 5.2 完整复制要求和准确复制要求的检测 5.2.1 对于目标对象为柱面非对齐备份的，按照以下步骤检测： a）准备两个型号相同、存储空间大小相同、不存在损坏扇区的电子数据存储介质，分别记为 A和B; b) 在A上随机写入任意数据后进行分区，并使A上存在隐藏数据扇区； c 使用复制工具将 A 复制到 B上： d） 计算A和B上存储的所有数据的MD5校验值，比较MD5校验值，如果一致，则判定符合完整 复制要求和准确复制要求，否则判定不符合完整复制要求和准确复制要求。 5.2.2 对于目标对象为柱面对齐备份的，按照以下步骤检测： a）准备两个型号相同、存储空间大小不同、不存在损坏扇区的电子数据存储介质，其中存储空间 较小的记为A，存储空间较大的记为B。 b） 在A上随机写入任意数据。 c) 将A分为两个分区，并使两个分区之间和第二个分区之后存在隐藏扇区。记A的第一个分区 起始扇区号为A，最后一个扇区号为A2，第二个分区起始扇区号为A3，最后一个扇区号为 A4，最后一个物理扇区号为A。并保证在B上第A扇区不位于簇边界上 d) 使用复制工具将A复制到B上。记B的第一个分区起始扇区号为B，最后一个扇区号为B2， 第二个分区起始扇区号为B，最后一个扇区号为B。 e) 计算 A 的 A扇区至 A—1 扇区和 B 的 B扇区至 B1 + A3—A1—1 扇区的数据的MD5 校验 值，比较MD校验值是否一致，如果不一致则判定不符合完整复制要求和准确复制要求。 f） 计算A的A扇区至A。扇区和B的B扇区至B+A—A2扇区的数据的MD5校验值，比较 MD5校验值是否一致，如果不一致则判定不符合完整复制要求和准确复制要求。 3
