## 说明

- 文件为规范原文（PDF / Word / 文本 / 拆分 md），点击总览页条目即可直接打开。
- **Word 文档（.docx 与老格式 .doc）均可在总览页弹窗内直接打开查看**（自动转换为 HTML 排版渲染，保留标题/段落/表格/粗斜体）；老格式 .doc 已通过 Word 自动转换，**原 .doc 文件仍保留供下载**（弹窗内「下载原 Word 文档(.doc)」按钮）；PDF 点击直接打开查看；扫描件 PDF 与图片无法浏览器内渲染，按提示打开原文查看。
- **法规条例等文本类条目（.html/.md/.txt）点击后自动排版显示**（章节「第X章」、条款「第X条」层级清晰、条目编号高亮），并附「查看/下载原文件」按钮。
- **支持全文检索**：总览页搜索框可检索名称/编号/备注，也可检索**条文正文全文**（已收录 241 份原文全文，命中条目名称下显示高亮片段，点击即可查看正文）。全文数据文件：`电子证据标准规范梳理\fulltext_data.js`（与总览页同目录，随页自动加载）；扫描件等无文本层文件（41 份）仅可按名称检索。
- **文件命名已去除手动排序序号**，按标准编号 / 名称自然排序；已删除 OCR 识别副本与重复条目。
- **同一标准只保留现行有效版本**（旧版移入 `00-历史版本` 目录）。
- **《规则全集》《计算机犯罪》原合集已拆分为按内容命名的独立小文件**（见 `14-拆分合集`）；拆出的内容若库中已有对应条目则不重复收录；拆出的网络犯罪司法解释等 7 项与电子证据相关的新条目已补入体系。
- 内容查询文本均来自原文文本层或公开渠道网络提取（非 OCR），保证正确无乱码。
- 知识库为按效力层级归整的副本，源文件保留在 `电子数据相关规范标准\` 原库。
- 数据源：`电子证据标准规范梳理\kb_data.json`；总览页：`电子证据标准规范体系·总览.html`。

## 参考资料库

- 独立页面：`电子证据标准规范梳理\电子证据参考资料库.html`（总览页顶部「📚 参考资料库」入口）。
- 用途：收录**非标准规范类**的辅助参考资料（研究解析、实务指引、解读汇编、电子书等），与按效力层级归整的标准体系分开管理。
- 功能：标题/全文搜索、分类筛选、点击条目在框架内排版显示、弹窗内返回按钮。
- 当前收录：4 篇研究解析文章（从《计算机犯罪》合集提取，含定罪量刑标准等表格）。
- 扩充方式：将电子书/资料放入 `电子证据知识库\16-参考资料\` 后运行 `电子证据标准规范梳理\_gen_ref_lib.py`（或告知助手补充），重新生成页面即可。
